# Lottery Game на Django

**Lottery Game** — это простое веб-приложение, реализованное на Django, которое имитирует лотерею. Пользователь может нажимать на кнопку "Старт", чтобы сгенерировать три случайных числа. На каждый 10-й запуск программа гарантированно выдает три одинаковых числа, что считается выигрышем. Интерфейс приложения выполнен с использованием Bootstrap, что делает его удобным и адаптивным.

---

## Основные функции

- **Генерация случайных чисел**: При каждом нажатии на кнопку "Старт" генерируются три случайных числа от 1 до 100.
- **Выигрышная комбинация**: На каждый 10-й запуск программа выдает три одинаковых числа, и пользователь видит сообщение "Вы выиграли!".
- **Сохранение состояния**: Счетчик запусков сохраняется между сессиями, даже после перезапуска сервера.
- **Удобный интерфейс**: Интерфейс приложения выполнен с использованием Bootstrap, что делает его современным и адаптивным.

---

## Как это работает

1. **Счетчик запусков**: Программа хранит количество запусков в базе данных. Каждый раз, когда пользователь нажимает "Старт", счетчик увеличивается на 1.
2. **Генерация чисел**:
   - Если счетчик кратен 10, программа генерирует три одинаковых числа.
   - В остальных случаях числа генерируются случайно.
3. **Сообщение о результате**: После генерации чисел пользователь видит сообщение "Попробуйте еще раз." или "Вы выиграли!" в зависимости от результата.
4. **Обнуление счетчика**: После 10-го запуска счетчик обнуляется.

## Установка и запуск

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/ваш-username/lottery-game.git
cd lottery-game
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Примените миграции
```bash
python manage.py migrate
```

### 4. Запустите сервер
```bash
python manage.py runserver
```

### 5. Откройте приложение
Перейдите по адресу [http://127.0.0.1:8000/](http://127.0.0.1:8000/) в браузере.

## Используемые технологии

- **Django**: Веб-фреймворк для создания приложения.
- **Bootstrap**: Фреймворк для создания адаптивного интерфейса.
- **AJAX**: Для асинхронной генерации чисел без перезагрузки страницы.
- **SQLite**: База данных для хранения счетчика запусков.
